# The MVP is the answer; Commit Decision is an enhancement layer

The v1 MVP is not a cut-down stand-in for a larger plugin. It is the complete answer to the gap InvenTree leaves: a full descendant-tree view, Build Order opportunity identification, checkbox multi-select, and one bulk "Create Build Orders" action. The richer per-node Commit Decision model is a v2+ enhancement layer, not the "real" version of which the MVP is a preview.
